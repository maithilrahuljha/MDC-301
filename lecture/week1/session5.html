Logistic regression: probability to decision

Promise: explain why logistic regression is a classifier, derive its log-loss from a Bernoulli likelihood, and choose evaluation measures that match the cost of mistakes.

Badge: W01-S05 · Probability Auditor

The idea in one pass

Logistic regression is a classification method despite “regression” in its name. It forms a linear score \(z=x^T\beta\), then applies the sigmoid \(\sigma(z)=1/(1+e^{-z})\) to produce a probability between zero and one. For a binary target, the fitted probability is compared with a decision threshold to produce a class label; the threshold is a decision rule, not a fact supplied by the model. The parameters are learned by minimizing negative log-likelihood, also called log-loss or cross-entropy. Unlike ordinary least squares, logistic regression has no closed-form coefficient solution, so an optimizer iteratively minimizes a convex, nonlinear objective. A coefficient changes log-odds, not probability directly; exponentiating it gives an odds ratio, while the probability change depends on the starting probability. Evaluate the decision with the confusion matrix and metrics such as precision, recall, F1, and ROC-AUC; when positives are rare, precision–recall analysis can be more informative than accuracy alone. Fit scaling inside a pipeline on training rows. If scikit-learn reports a convergence warning, scaling features is usually a better first response than merely raising the iteration limit. Choose any threshold using validation data or cross-validation, then report performance once on untouched test data. This makes the final score a check on the workflow rather than another tuning signal.

Log-loss from maximum likelihood

Assume \(y_i\mid x_i\sim\operatorname{Bernoulli}(p_i)\) with \(p_i=\sigma(x_i^T\beta)\). The likelihood of the observed data is

\[L(\beta)=\prod_{i=1}^{n}p_i^{y_i}(1-p_i)^{1-y_i}.\]

Each factor is \(p_i\) when \(y_i=1\) and \(1-p_i\) when \(y_i=0\). The log-likelihood is

\[\ell(\beta)=\sum_{i=1}^{n}\left[y_i\log p_i+(1-y_i)\log(1-p_i)\right].\]

Maximising \(\ell\) is the same as minimising \(L=-\ell\), the log-loss:

\[L(\beta)=-\sum_{i=1}^{n}\left[y_i\log p_i+(1-y_i)\log(1-p_i)\right].\]

Transcribed and checked against the supplied custom booklet PDF, Chapter 12.1, printed pages 45–46. The symbol \(L\) follows the booklet’s local notation: it denotes the likelihood in one line and the negative log-likelihood in the log-loss display.

One gradient-descent step

The booklet gives the update \(\beta^{(t+1)}=\beta^{(t)}-\eta X^T(\hat p^{(t)}-y)\), where \(\eta>0\) is the learning rate. Here is one hand-checkable step using an intercept column:

Let \(X=\begin{bmatrix}1&1\\1&2\end{bmatrix}\), \(y=\begin{bmatrix}0\\1\end{bmatrix}\), \(\beta^{(0)}=\begin{bmatrix}0\\0\end{bmatrix}\), and \(\eta=0.1\). Then \(\hat p^{(0)}=(0.5,0.5)^T\), so

\[X^T(\hat p^{(0)}-y)=\begin{bmatrix}1&1\\1&2\end{bmatrix}^T\begin{bmatrix}0.5\\-0.5\end{bmatrix}=\begin{bmatrix}0\\-0.5\end{bmatrix}.\]

Therefore \(\beta^{(1)}=\beta^{(0)}-0.1(0,-0.5)^T=(0,0.05)^T\). The positive slope makes the model assign a larger probability to the example with \(x=2\).

The update is transcribed from the supplied booklet, Chapter 12. The two-row numerical demonstration is a teaching example, not a quiz-bank item.

Predict, then reveal

Before opening the explanation: when the linear score is \(z=0\), what probability does the sigmoid return?

Reveal the answer and why

\(\sigma(0)=1/(1+e^0)=1/2=0.5\). A score of zero means equal model odds for the two classes before applying any separate decision rule.

Decision-rule note: choose a decision threshold on validation data or cross-validation, then evaluate once on the untouched test set. Tuning a threshold on test labels is leakage.

Break it / fix it · convergence warning

Too few optimizer iterations on unscaled features can leave logistic-regression coefficients only partly optimized:

# Deliberately fragile: no feature scaling and only one iteration.
model = LogisticRegression(solver="lbfgs", max_iter=1)
model.fit(X_train_unscaled, y_train)  # May raise a ConvergenceWarning
Show the fix and the lesson

Scale features inside a pipeline fitted on training rows, use a fixed solver, and allow enough iterations: make_pipeline(StandardScaler(), LogisticRegression(solver="lbfgs", max_iter=1000)). The warning is not a Python syntax error; it says the optimizer may not have reached its solution. Scaling is usually a better first fix than only increasing max_iter. Then choose any threshold on validation data, not test data.
