Week 1 / Day 0 student guide

One-page setup guide · no build tools

Publish your own course copy.

Recommended before Session 1: make a public copy, turn on GitHub Pages, and test the Week 1 page. Expected class timetable and device details are not supplied; your instructor will fill those in.

Do these steps in order

  1. Sign in or create a GitHub account. Do this before class if possible. Never share your password, recovery code, or two-factor code with anyone.
  2. Fork the public course repository. Open maithilrahuljha/MDC-301, select Fork, and create the copy under your own account. Keep the repository Public for free GitHub Pages. If the instructor provides a different template link, use that link instead.
  3. Enable Pages. In your copy, open Settings → Pages. Under Build and deployment, choose Deploy from a branch, branch main, folder /(root), then select Save. Do not choose /docs or gh-pages.
  4. Wait for the first deploy. GitHub may take up to about 10 minutes. Open the Pages URL shown in Settings, usually https://<your-username>.github.io/MDC-301/. The root page should link into /lecture/index.html.
  5. Test the course path. Open Week 1, Session 3, and Session 5. Then open Weeks 2–8; each should show a styled “Coming in Week N” page, not a 404.
  6. Keep work in the right folders. Add code under exercises/weekN/, notes under notes/ only if you accept public visibility, and badge/reflection updates in progress.md. Do not edit files inside lecture/ unless the weekly instructions ask you to.

Optional local preview

After cloning your own repository, run this from its root in a terminal:

python -m http.server 8000

Expected: a line like Serving HTTP on 0.0.0.0 port 8000 (wording varies by Python version). Open http://localhost:8000/ in the same computer’s browser; press Ctrl+C to stop. If Python is not installed, skip local preview and use the published Pages URL.

Public means world-readable. GitHub Free Pages requires a public repository. Do not add passwords, API keys, grades, student IDs, contact information, private notes, or confidential data. Keep personal notes outside the repository. This site has no server-side code; the optional code cells run in your browser and the badge flags are local to that browser.

Use the read-only course site to follow the lesson, download the plain starter files, and ask the instructor for the approved offline/lab submission route.
