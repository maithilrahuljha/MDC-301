A small, practical tool map

Python and the data tools

Python is the language; NumPy stores numerical arrays; pandas helps inspect labelled tables; Matplotlib makes plots for checking data and model behaviour.

scikit-learn

Provides estimators, preprocessing, train/test splitting, cross-validation, and metrics through a consistent fit/transform/predict style.

Read X as a table: each row is one example and each column is one feature, so its shape is usually (n_samples, n_features). The one-dimensional target y contains one known answer per row for supervised learning.

model.fit(X_train, y_train)       # learn from training examples
predictions = model.predict(X_test) # predict for held-out examples

fit learns model parameters; a transformer’s transform changes the feature table; predict returns model outputs. Constructor settings such as max_iter are chosen before fitting, while learned attributes such as coef_ appear after fitting.

Session outline

1 · Data tools

Use NumPy arrays for numerical features, pandas for labelled tables, Matplotlib for inspection, and scikit-learn for estimators and model selection.

2 · Estimator API

Trace fit(X_train, y_train), inspect coef_ or feature_names_in_, then call predict(X_new).

3 · Make the split before fitting

Keep test rows and labels out of scaler fitting, feature choice, and hyperparameter choice. Do not use a test score as a tuning signal.

4 · Pipeline rehearsal

Wrap preprocessing and the estimator in one pipeline so cross-validation refits each transformation only on its training fold.

Selected derivation · mean squared error

For observed targets \(y_i\) and predictions \(\hat y_i\), square each residual, sum across examples, and divide by the number of examples:

\[\operatorname{MSE}(y,\hat y)=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat y_i)^2.\]

For a fixed model, this is the loss used to compare predictions on a chosen split. It is not permission to select a model repeatedly on the held-out test set.

Scope: custom booklet, Chapters 5–7. Further reading: scikit-learn’s Getting Started guide explains the estimator API and pipelines; its common pitfalls guide explains how pipelines reduce leakage risk.

Break it / fix it · one-dimensional feature input

The values are numeric, but scikit-learn expects a two-dimensional feature matrix:

X = np.array([1, 2, 3, 4])
model.fit(X, y)  # Deliberately wrong: X has shape (n_samples,)
Show the fix and the lesson

Use X.reshape(-1, 1) or X[:, np.newaxis] to get shape (n_samples, 1). The 2-D shape is the scikit-learn API rule, not a bug in the estimator. Separately, split before fitting a scaler; a pipeline fitted on training rows prevents test-distribution leakage.
