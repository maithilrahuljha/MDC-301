# Week 1 downloadable starters

There is one plain `.py` starter per 90-minute session. They are also readable source examples and match the lecture story. Download them before class if connectivity is uncertain.

| Session | File | Intended practice |
|---|---|---|
| 1 | `session1.py` | Features, target, supervised/unsupervised labels, and lifecycle order |
| 2 | `session2.py` | scikit-learn estimator API, feature shape, and training-only preprocessing |
| 3 | `session3.py` | OLS fit, coefficients, prediction, and residual inspection |
| 4 | `session4.py` | Multiple features, polynomial basis, and regularization |
| 5 | `session5.py` | Scaled logistic regression, probabilities, labels, and metrics |

The browser cells on Sessions 3 and 5 are optional and show expected output even if Pyodide cannot load. A `.py` file needs Python and the listed packages to execute. If the browser is offline and Python is not installed, there is no local execution engine; read the starter, use the printed expected result, annotate the derivation, or ask to use a campus/lab computer or instructor demonstration. Do not install software on a managed device without permission.

No file needs real student data, API keys, or account credentials.
